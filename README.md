# QuantumSimulations

**An inspectable introduction to mapping fermionic operators onto qubits and optimizing their energy with VQE.**

The [molecules_qiskit.ipynb](molecules_qiskit.ipynb) notebook brings Hamiltonian construction, quantum-circuit optimization and visual explanation into one sequence. It explores molecularly motivated examples labeled H₂, H₂O, HCl and citric acid using simplified, manually specified operators.

[Open the notebook in Colab](https://colab.research.google.com/github/FyodorAmanov1/quantumSimulations/blob/main/molecules_qiskit.ipynb)

## What the notebook contains

- Fermionic operators built with Qiskit Nature's `FermionicOp`.
- Jordan–Wigner mapping from fermionic terms to qubit operators.
- A parameterized `TwoLocal` ansatz with rotation and entangling gates.
- Variational Quantum Eigensolver optimization with SPSA.
- Matplotlib animations illustrating molecularly inspired electron clouds.

The useful learning path is to follow one operator through mapping, ansatz construction and energy minimization before changing the operator or circuit depth.

## Run locally

Create and activate an isolated Python environment, then launch Jupyter:

```bash
python -m pip install jupyterlab
python -m jupyter lab
```

Open `molecules_qiskit.ipynb` and inspect its dependency cells. Its imports use NumPy, Matplotlib, Qiskit, Qiskit Nature, Qiskit Aer, Qiskit Algorithms and Pillow. The notebook uses legacy Qiskit primitives and does not provide a pinned environment; SDK compatibility may need adjustment before execution.

The GIF files are generated by notebook cells and are not checked into this repository. Saved notebook output can be inspected without a separate image download.

## Scientific scope

The manually specified Hamiltonians are educational models. Their molecule labels do not establish chemically validated ground-state energies. An energy comparison needs a consistent basis, electron-number sector, nuclear-repulsion convention and independent classical reference.

The animated clouds use illustrative random point distributions rather than orbital densities derived from the optimized quantum state. Circuit simulation demonstrates the computational workflow but does not establish physical-device execution or quantum advantage.
